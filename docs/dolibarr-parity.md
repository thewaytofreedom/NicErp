# Dolibarr → NicErp 实现与验收清单

基准：本机 Dolibarr 12.0.3；2026-10-10 只读查询的真实配置见 [dolibarr-audit.json](dolibarr-audit.json)。23 个独立启用模块，实体 1 有 21 个，实体 2 有 6 个；用户与多公司为全局模块。以本机源码及配置为准，不按新版 Dolibarr 猜测。原库仅查询，NicErp 代码与数据库独立。

## 验收定义

“完成”必须有字段、界面、服务端权限、公司边界、状态转换、失败回滚、打印/导出以及对应业务测试；只有同名菜单或部分基础流程不算全部对齐。配置开关不等于真实共享关系：多公司的实际共享配置已记录在快照 entities 中；实现与权限验收仍未完成。当前不是全部实现完成。

## 已证实的本机规则

- `PRODUIT_USE_SEARCH_TO_SELECT=3`，产品选择用搜索。`PRODUIT_MULTIPRICES`、客户专属/数量售价及核心子产品开关为 0；ProductMixer 自有组合功能另行启用，不能混为一谈。
- `PROPALE_VALIDITY_DURATION=15`；报价 azur、订单 proforma、发票 sponge、采购 muscadet PDF 模板。编号插件含定制 `mod_facture_commande_ref`，应核实订单与发票编号关系。
- MyProduct 的 `product_rpn` 构成传递关联图；共享替代号把产品连接成组，`customcode` 缓存整组替代号。NicErp 应保持可编辑原始号码并实时解析，不能只做单产品数组匹配。
- 报价导入 1=任意原厂/进口；2=有中国原厂只选中国原厂，否则任意货源含 WD；3=中国原厂/进口；4=有中国原厂只选中国原厂，否则中国货源含 WD；5=SN/海外；6=WD；7=直接产品编号。候选仅可销售，按售价最低选取，导入单价优先于产品价格。原系统未知或过期产品保留为零价自由明细。货源白名单来自本机定制源码，年份不是通用算法。
- MyDiscount 的三种动作分别是覆盖所选行折扣、按百分比减少所选行单价、删除所选行；备注/小计应排除金额操作。金额与税额必须由服务端 Decimal 重算。
- 当前库存开关：发货扣库、供应商订单确认增库、支持服务库存、允许负数调拨。NicErp 当前采购收货增库及禁止负库存与该配置不同，需实现可配置策略并防止重复入库。
- 多公司共享能力开关为 1，并不证明所有实体互相共享；已读取具体关系：1/2 的产品、价格、供应商价格、库存、单位、报价、发票及大多数编号互相共享；订单只有实体 2 读取实体 1，账户只有实体 1 读取实体 2。必须逐资源实现权限闭包。
- 本机库存在 16 个产品、12 条替代号、2 条组合关联、3 个单位、3 张报价、6 张销售订单、1 张采购订单、5 张发票、3 张发货单和 174 条库存流水。银行账户/付款/供应商发票为空；这些模块仍应按启用功能验收，不能以无数据为由忽略。

## 执行记录

1. 完成只读模块/开关/字段/表结构快照与源码定位。
2. 本批已实现：产品用途/型号/货源、实时传递替代号；7 种报价货源偏好及直接编号/唯一匹配模式、价格优先级、自由明细与逐行提示；服务端 Decimal 批量折扣/改价/删除；分组标题/层级/嵌套小计及打印折叠，编辑器支持复制/移动/删除整组；报价 15 天有效期、参考号、交付/付款信息、内部备注、接受/拒绝、返回草稿、复制与草稿删除；多联系人；供应商报价/价阶/折扣/汇率/有效期/交货天数及采购取价；按产品/客户/发票/日期的成本快照毛利；资金账户资料、独立收支、同币种原子转账、流水冲销与对账/取消；嵌套组合、循环校验、叶子用量合并、成本与出入库快照、各仓可组装数量；实际 11 种贸易术语选择及可维护的付款/配送字典。
3. 本批额外修复：局域网 HTTP 下使用 getRandomValues 生成幂等键，避免安全上下文限制导致收发货/付款弹窗失败；整数输入校验支持层级/交货天数；导入自由明细保留原始编号。
4. 验证：独立 nicerp_test API 回归覆盖既有 17 项场景与新增 3 组详细规则；类型检查和生产构建通过。浏览器最终回归已通过：报价→销售→发货、收付款、批量改价、分组打印与内部备注隐藏、联系人/供应商价目表/毛利页面、独立资金收支及对账/取消/冲销、组合库存、公司切换、移动布局和只读权限；浏览器模拟缺失 randomUUID 的局域网环境。
5. 仍未完成：本表未逐项勾销的其他功能，尤其逐项权限/用户组、实际多公司资源共享、独立发货与收货单完整生命周期、采购审批、部分/合并/贷项/进度发票、付款汇兑、原配置库存触发策略、附件/邮件、完整 Excel/ODS 导入、PDF 模板细节、组合物理属性同步、导入导出方案保存。源码/配置盘点不等于登录界面已完整实测；已请求 Dolibarr 测试登录方式用于逐页验收。
